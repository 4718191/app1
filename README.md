

# 유통기한 관리 (foodly)
- 집에 있는 음식의 유통기한을 관리하는 iOS 앱입니다. SwiftUI와 SwiftData로 제작되었습니다.

## 주요 기능
### 📋 음식 관리
- 음식 이름, 유통기한, 보관 방법(냉장/냉동/실온)을 등록
- 음식 사진 첨부 (사진 라이브러리에서 선택)
- 항목 수정 및 삭제 (스와이프로 삭제)
- 모든 데이터는 앱을 껐다 켜도 유지됨 (SwiftData 로컬 저장)
### 🎨 목록 화면
- 유통기한이 임박한 순서로 자동 정렬
- 유통기한 상태에 따라 색상으로 구분
🔴 빨강: 유통기한 지남
🟠 주황: 3일 이내 임박
🟢 초록: 여유 있음
- 음식 이름으로 검색
- 냉장/냉동/실온 카테고리별 필터링
- 등록된 음식이 없을 때 안내 화면 표시
### 🔔 알림
- 유통기한 하루 전, 오전 9시에 자동 알림 발송
- 항목 삭제 시 예약된 알림도 함께 취소
### 📊 통계
- 전체 보관 중인 음식 개수
- 유통기한 상태별(지남/임박/여유) 막대그래프
- 카테고리별 보유 개수 막대그래프
### ⚙️ 설정
- 라이트 모드 / 다크 모드 / 시스템 설정 따르기 중 선택 가능
- 화면 구성
- 하단 탭 바로 세 화면을 오갈 수 있습니다.

## 탭	설명
- 목록	등록된 음식 목록, 검색, 카테고리 필터, 추가/수정/삭제
- 통계	유통기한 상태 및 카테고리별 분포 그래프
- 설정	화면 모드(라이트/다크) 설정

## 기술 스택
- SwiftUI — 전체 UI 구성
- SwiftData — 로컬 데이터 저장 및 관리
- PhotosUI — 사진 선택 (PhotosPicker)
- UserNotifications — 유통기한 임박 알림
- Swift Charts — 통계 화면의 막대그래프

## 데이터 모델
Food 항목은 다음 정보를 가집니다.

| data | name |
|---|---|
| name | 음식 이름 |
| expiryDate | 유통기한 |
| category | 보관 방법 (냉장 / 냉동 / 실온) |
| imageData | 첨부 사진 (선택) |



## 실행 방법
1. Xcode에서 프로젝트 열기
2. 상단에서 시뮬레이터 또는 실제 기기 선택
3. 실행(▶) 버튼 클릭
4. 실제 기기에서 처음 실행할 경우, 기기의 설정 > 일반 > VPN 및 기기 관리에서 개발자 프로필을 신뢰해야 앱이 실행됩니다.

## 앞으로 추가 가능한 기능
